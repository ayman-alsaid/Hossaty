This directory classifies the evidence used by the public case study.

- Next.js 14 + Fastify 5 architecture;
- PostgreSQL 16 + pgvector;
- Redis + BullMQ background processing;
- curriculum document ingestion;
- four-signal tutoring context;
- structured vision homework review;
- weakness detection feeding future personalization;
- six-dimensional ratings;
- recurring session generation;
- bidirectional payment-record confirmation;
- study groups / achievements / leaderboards;
- per-teacher AI quotas;
- EN/AR RTL interface;
- 28-table documented data model;
- 50+ documented API endpoints.

## VERIFIED IN A CONTROLLED RUN

### PDF ingestion example

The primary source records a six-page test PDF producing **69 indexed chunks** on the live deployment.

Scope: this is evidence for that controlled document-processing run only.

It is not a benchmark for arbitrary documents or proof of retrieval quality.

## Evidence principle

Implementation evidence supports architecture claims. Educational-impact claims require educational-impact evidence.
